إزاي تعمل التوكن؟
  1. افتح github.com/settings/tokens
  2. Generate new token → اختر الريبو alrehab-lab-site
  3. صلاحية Contents: Read and write + Metadata: Read
  4. Expiration: سنة → أنشئ → انسخ التوكن والصقه فوق

أي تعديل تحفظه يظهر على الموقع خلال دقيقة تقريباً

  • بيانات المعمل — الهاتف، الإيميل، المواعيد، الفروع، روابط السوشيال.
  • نصوص الموقع — كل عنوان وجملة في الصفحات (عربي + إنجليزي).
  • دليل التحاليل — إضافة تحليل، تغيير السعر، تعديل شروط الصيام.
  • معرض التوعية والتعاقدات — تغيير الصور واللوجوهات من مكتبة الصور.
  • نسخ احتياطي — نزّل نسخة من المحتوى قبل أي تغيير كبير.
