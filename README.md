# معامل الرحاب للتحاليل الطبية — AL Rehab Medical Lab

موقع تعريفي وتوعوي لمعامل الرحاب: عربي/إنجليزي، وضع ليلي، دليل تحاليل بشروط الصيام،
خدمة السحب المنزلي، معرض تصاميم التوعية، نصائح طبية، تعاقدات الشركات، ونموذج آراء وشكاوى.

**الموقع المباشر:** https://al-rehab-lab.github.io/alrehab-lab-site/

## الصفحات
الرئيسية · دليل التحاليل · السحب المنزلي · تصاميم التوعية · النصائح الطبية · التعاقدات · تواصل معنا · الآراء والشكاوى · الخصوصية · شروط الاستخدام

## تعديل البيانات
- `js/data.js` — رقم الواتساب، الإيميل، الفروع، التحاليل والأسعار، النصائح، البوسترات، التعاقدات
- `js/i18n.js` — كل النصوص الثابتة بالعربي والإنجليزي
- `assets/posters/` — صور معرض التوعية

## تشغيل محلي
الموقع ستاتيك بالكامل: افتح `index.html` مباشرة، أو:

```bash
python3 -m http.server 8080
```

## النشر
GitHub Pages من فرع `main` والمجلد `/ (root)`.
