# معامل الرحاب للتحاليل الطبية — AL Rehab Medical Lab

موقع تعريفي وتوعوي + **لوحة تحكم كاملة** لتعديل المحتوى ونشره مباشرة.

- **الموقع:** https://al-rehab-lab.github.io/alrehab-lab-site/
- **لوحة التحكم:** https://al-rehab-lab.github.io/alrehab-lab-site/admin.html

## الصفحات
الرئيسية · دليل التحاليل · السحب المنزلي · تصاميم التوعية · النصائح الطبية · التعاقدات · تواصل معنا · الآراء والشكاوى · الخصوصية · شروط الاستخدام

## لوحة التحكم
تعدّل ملف `content.json` وترفعه إلى هذا الريبو عبر GitHub API، والموقع يقرأ الملف عند كل زيارة.
لا تحتاج سيرفر ولا قاعدة بيانات.

1. افتح `admin.html`.
2. ادخل بـ GitHub **Fine-grained Token** بصلاحية **Contents: Read and write** على هذا الريبو.
3. عدّل أي شيء ثم اضغط **حفظ ونشر التعديلات** — يظهر على الموقع خلال دقيقة.

التوكن يُحفظ في متصفحك فقط (localStorage).

## بنية الملفات
- `content.json` — كل المحتوى القابل للتعديل (يُنتجه زر «حفظ ونشر»).
- `js/data.js` — البيانات الافتراضية (احتياطي لو حُذف content.json).
- `js/i18n.js` — النصوص الافتراضية عربي/إنجليزي.
- `js/content.js` — يقرأ content.json ويدمجه فوق الافتراضي.
- `admin/` + `admin.html` — لوحة التحكم.
- `assets/uploads/` — الصور المرفوعة من اللوحة.
